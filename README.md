# moonframehq/homebrew-tap

Homebrew tap for [Moonframe](https://moonframe.dev) and the apps built on it.

```sh
brew install moonframehq/tap/moonframe
```

`brew install` resolves both formulae and casks, so `--cask` is not required.
To install by short name and pick up updates later, tap once first:

```sh
brew tap moonframehq/tap
brew install moonframe
```

| Package | Kind | Source |
| --- | --- | --- |
| `moonframe` | Cask | [moonframehq/moonframe](https://github.com/moonframehq/moonframe) |

Each file is written by its own project's release workflow. Do not edit them
here by hand: the next release of that project overwrites the file.
